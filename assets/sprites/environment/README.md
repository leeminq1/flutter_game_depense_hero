# Environment Sprite Slots

This folder reserves paths for stage props and landmarks used by the 30-stage campaign.

Reference files:

- `assets/sprites/manifest/environment_visual_slots.json`
- `docs/design-docs/stage-art-bible.md`
- `docs/design-docs/environment-asset-matrix.md`
- `docs/design-docs/size-and-silhouette-rules.md`

Guidelines:

- Props should generally read below towers in saturation and importance.
- Landmarks should support stage identity but not look like buildable towers.
- Use shared props first, then crest-stage landmarks.
