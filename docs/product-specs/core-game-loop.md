# Core Game Loop

## Session Loop

1. Preview map and enemy path.
2. Spend starting currency on tower placement.
3. Start or continue waves.
4. React with real-time tower placement, upgrades, sell, or reposition systems if allowed.
5. Survive escalating enemy compositions.
6. Earn rewards, then return to meta progression.

## Tower Roles To Start

- Single-target burst
- Area control / splash
- Slow or utility support

## Enemy Roles To Start

- Basic runner
- Tank
- Fast evasive unit
- Support or shielded unit

## Constraints

- Session length target should remain compact.
- The first content set should already demonstrate counterplay.
- Upgrade text and visuals must be understandable during active play.
- Paths are fixed per stage, but stage layout and path shape should evolve across the campaign.
- New stages should increase complexity through map geometry, enemy composition, and unlock pressure.
- The player must be allowed to place new units and structures during active waves.

## Stage Structure

- Each stage uses a fixed enemy route or a fixed set of routes.
- Stage progression changes the battlefield rather than asking the player to learn a new mode each time.
- New tower unlocks should appear often enough that stage progression feels meaningful.
