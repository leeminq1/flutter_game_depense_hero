# Core Game Loop

`Pixel Guard: Wave`는 짧은 전투를 반복하며 성을 지키는 2D 타워 디펜스다. 전투마다
건물은 새로 짓지만, 플레이어 진행도와 메타 업그레이드는 로컬 저장소에 남는다.

## 화면 흐름

1. `TitleScreen`
   - `새 게임`: 확인 팝업 없이 즉시 진행도를 초기화하고 Stage 1 캠프로 들어간다.
   - `이어하기`: `currentCampaignStage > 1`일 때만 활성화된다. Stage 1만 중단/실패한
     상태에서는 동작하지 않는다.
   - `설정`: 오디오 설정 화면으로 이동한다.
2. `HomeScreen` / Camp Hub
   - 현재 Stage, 별, 진행 정보를 보여준다.
   - 상단 초록색 재화 칩은 표시하지 않는다. `softCurrency` 데이터는 저장 구조에 남아
     메타 업그레이드에 사용한다.
   - Stage 선택 버튼은 현재 테스트 빌드에서 전체 해금된다.
3. `GameScreen`
   - 준비 단계에서 타워/성벽/영웅을 배치한다.
   - Wave 시작 후에는 전투가 진행되고, 적이 성에 도달하면 하트가 감소한다.
   - 각 Wave 후 회복 구간에서 추가 배치와 업그레이드를 할 수 있다.
   - 결과 팝업은 클리어/실패, 별, 보상, 다음 Stage 이동을 처리한다.
4. `SettingsScreen`
   - 화면 텍스트는 한국어다: `설정`, `오디오`, `오디오 켜기`, `전체`, `효과음`.
   - 실제 BGM 경로가 없으므로 음악 슬라이더는 없다.
   - 튜토리얼 리셋 카드와 버튼은 없다.

## 전투 규칙

- 기본 목표는 모든 Wave를 버티고 성 하트가 0이 되지 않게 하는 것이다.
- 성 하트는 기본 3이며, 보스가 성까지 도달하면 최소 2 피해를 준다.
- 일반 적은 경로를 따라 이동하고, 성벽이 길을 막으면 우회하거나 성벽을 공격한다.
- 보스는 성벽을 때릴 때 직접 피해와 별도 쇼크웨이브 범위 피해를 만든다.
- 타워 접촉 피해는 보스/중장 적이 이동 중 가까운 타워를 때리는 별도 피해다.
- 영웅은 Stage 시작 전 선택하고 전투 중 한 명만 배치한다. 회복 구간에서 한 번 무료
  부활할 수 있지만, 특정 주사위 카드가 추가되면 막힐 수 있다.

## 성장 규칙

- 건물은 Stage마다 초기화된다.
- 기본 배치 레벨은 Stage에 따라 오른다.
  - Stage 1~9: Lv1
  - Stage 10~19: Lv2
  - Stage 20~30: Lv3
- 최대 전투 레벨은 Lv4다.
- `첫 마법사 탑 +1레벨` 주사위는 Stage 기본 레벨 위에 +1을 더하되 Lv4를 넘지 않는다.

## 성공 기준

- 플레이어가 Stage를 클리어하면 별과 보상을 얻고 다음 Stage가 열린다.
- 실패해도 일부 보상/진행 기록은 남을 수 있다.
- 프로덕션 빌드는 `kUnlockAllCampaignStagesForDevelopment = false`이며, 전체 Stage를
  일괄 해금하지 않는다.
