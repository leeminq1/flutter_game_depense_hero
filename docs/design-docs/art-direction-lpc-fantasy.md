# Art Direction: LPC Fantasy

## Decision

Adopt a pixel-fantasy direction optimized for the Universal LPC character generator.

## Why This Works

- The generator supports many modular humanoid combinations.
- Tower defense enemies benefit from class-like silhouettes more than hyper-unique anatomy.
- Production speed stays high because one base asset system can produce many stage variants.

## Enemy Visual Taxonomy

- Light units: hooded rogues, scouts, skirmishers
- Tank units: armored soldiers, undead heavy infantry
- Support units: priests, shamans, cult adepts
- Elite units: champion knights, cursed captains, warlocks

## Stage Progression Look

- Early stages: villages, roads, forests, bandits
- Mid stages: graveyards, ruins, corrupted chapels, undead
- Late stages: fortress roads, cursed battlements, elite armored factions

## Constraint

If we stay with LPC as the main enemy pipeline, the first content roadmap should favor humanoid fantasy enemies over beasts and giant monsters.
