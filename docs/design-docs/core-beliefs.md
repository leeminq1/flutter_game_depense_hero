# Core Beliefs

## Harness Beliefs

- `AGENTS.md` is a map, not the encyclopedia.
- The repository should explain itself in small, durable documents.
- Plans are first-class artifacts, not disposable chat residue.
- Agents should load context progressively rather than starting with everything.

## Game Beliefs

- Readability beats visual noise.
- Content scale matters as much as feature depth.
- Tower defense balance is a data problem first and a code problem second.
- Combat should be inspectable enough that failures can be understood and tuned.
- Early systems should favor reuse, not one-off hero mechanics.

## Production Beliefs

- We should be able to add a tower, enemy, and wave set without re-architecting the game.
- Asset generation should accelerate ideation, but export quality needs explicit standards.
- The project should remain friendly to solo or small-team iteration.
