# Stage 5 작업 카드

## 상태

- 코드 적용 완료
- 플레이 검증 대기

## Stage 5 목표

- Stage 1~4에서 배운 규칙을 한 번에 시험한다
- 빠른 압박, 중장, 사방 분산, 후퇴 거점을 모두 사용하게 만든다
- 초반 중앙 성 구간의 마무리 Stage로 둔다

## 전장 개요

- 성 위치: 중앙 고정
- 적 스폰: 북 / 동 / 남 / 서 4방향 모두 사용
- 핵심 위험: 동쪽 중장 + 남쪽 지휘관 + 북/서 분산 압박
- 플레이 감정 한 줄: `초반에 배운 모든 판단을 한 번에 요구하는 Stage`

## Cycle 구성

- Cycle 1: 빠른 동쪽 압박 + 사방 기본 압박
- Cycle 2: 사방 물량 증가
- Cycle 3: 동쪽 중장 체크
- Cycle 4: 동쪽 중장, 남쪽 지휘관, 북/서 분산을 함께 처리

## 좌표 규칙

- 북쪽 루트:
  - `[6,0] -> [6,1] -> [6,2] -> [5,2] -> [4,2] -> [4,3] -> [4,4] -> [5,4] -> [6,4] -> [6,5]`
- 동쪽 루트:
  - `[13,5] -> [12,5] -> [11,5] -> [10,5] -> [10,6] -> [9,6] -> [8,6] -> [7,6]`
- 남쪽 루트:
  - `[7,13] -> [7,12] -> [8,12] -> [9,12] -> [9,11] -> [9,10] -> [8,10] -> [7,10] -> [6,10] -> [6,9] -> [6,8] -> [6,7]`
- 서쪽 루트:
  - `[0,8] -> [1,8] -> [2,8] -> [3,8] -> [4,8] -> [4,7] -> [4,6] -> [5,6]`

## 장애물 의도

- 북쪽은 Stage 1의 우회 감각을 다시 사용한다
- 동쪽은 중장이 들어오는 길 주변을 좁혀 우선 대응을 요구한다
- 남쪽은 마지막 Cycle의 지휘관 압박이 늦게 몰리도록 만든다
- 서쪽은 빠른 분산 압박으로 플레이어 시선을 흔든다

## 장애물 좌표

- 북쪽 성벽:
  - `[5,3]`, `[6,3]`, `[7,3]`, `[8,3]`
- 동쪽 차단 벽:
  - `[10,7]`, `[11,7]`
- 남쪽 우회 벽:
  - `[5,9]`, `[7,9]`, `[8,9]`
- 서쪽 차단 벽:
  - `[3,6]`, `[3,7]`

## 검증 체크리스트

- Stage 1~4에서 배운 판단이 모두 필요하게 느껴지는가
- 마지막 Cycle이 초반 구간의 마무리처럼 느껴지는가
- 실패했을 때 원인이 방향 우선순위와 타워 역할 판단으로 읽히는가
