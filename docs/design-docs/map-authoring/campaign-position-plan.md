# 30 Stage 성 위치 계획

이 문서는 30개 Stage 전체에서 성 위치가 어떻게 이동하는지 정리한 기준 문서다. 핵심은 무작위 이동이 아니라 “5 Stage 단위 학습 구간”으로 위치를 바꾸는 것이다.

## 사분면 기준

화면 중앙을 기준으로 다음처럼 읽는다.

```text
2사분면(좌상단)      1사분면(우상단)

3사분면(좌하단)      4사분면(우하단)
```

## 구간별 목표

| Stage 구간 | 성 위치 구간 | 학습 목표 |
| --- | --- | --- |
| Stage 1~5 | 중앙 | 사방 방어 기본기 |
| Stage 6~10 | 1사분면 | 우상단 성 위치와 짧은 동쪽 압박 |
| Stage 11~15 | 2사분면 | 좌상단 성 위치와 서쪽 긴급 방어 |
| Stage 16~20 | 3사분면 | 좌하단 성 위치와 남쪽 성문 압박 |
| Stage 21~25 | 4사분면 | 우하단 성 위치와 동쪽 성 앞 압박 |
| Stage 26~30 | 중앙 회귀/재압박 | 이전 구간 문법 재시험과 최종 공성전 |

## 좌표 계획

| Stage 구간 | 성 좌표 흐름 |
| --- | --- |
| Stage 1~5 | `[6,6]`, `[6,6]`, `[6,6]`, `[6,6]`, `[6,6]` |
| Stage 6~10 | `[7,5]`, `[8,5]`, `[8,4]`, `[9,5]`, `[9,4]` |
| Stage 11~15 | `[4,5]`, `[5,4]`, `[4,4]`, `[3,4]`, `[3,3]` |
| Stage 16~20 | `[5,8]`, `[4,8]`, `[5,9]`, `[4,9]`, `[3,9]` |
| Stage 21~25 | `[8,8]`, `[9,8]`, `[8,9]`, `[10,9]`, `[10,10]` |
| Stage 26~30 | `[6,6]`, `[4,4]`, `[9,4]`, `[4,9]`, `[9,9]` |

## 구간별 해석

### Stage 1~5

- 플레이어가 맵 구조보다 방어 역할과 사방 압박 자체를 먼저 익히는 구간

### Stage 6~10

- 우상단 구간
- 하단 넓은 공간과 짧은 동쪽 압박을 동시에 이해시키는 구간

### Stage 11~15

- 좌상단 구간
- 서쪽 긴급 방어와 오른쪽 장거리 화력 거점을 학습시키는 구간

### Stage 16~20

- 좌하단 구간
- 남쪽과 서쪽의 짧은 압박, 북동쪽의 긴 후퇴 사선을 함께 다루는 구간

### Stage 21~25

- 우하단 구간
- 동쪽 성 앞 전투와 남쪽 넓은 킬존을 동시에 다루는 구간

### Stage 26~30

- 이전 구간에서 배운 문법을 다시 꺼내 쓰는 최종 시험
- 마지막 Stage는 한쪽으로 치우치지 않고 종합 압박을 견디는 구조

## 장애물 배치 원칙

- 성 가까운 곳: 성벽 조각 중심
- 성에서 먼 곳: 우물, 마차, 상자, 울타리 중심
- 짧은 압박 방향: 잠깐 늦추는 수준의 좁은 방어선
- 긴 우회 방향: 사선 보상이 살아나는 열린 공간 유지

## 구현 메모

- Stage 6부터는 성 좌표를 Stage 데이터가 직접 들고 있어야 한다.
- 경로 검증은 각 방향이 해당 변에서 시작하고, 성 주변 한 칸에서 끝나는지 확인한다.
- Stage 16~20부터는 “좌하단 성 위치 문법”이 실제 앱에서 읽혀야 한다. 단순히 좌표만 바뀐 것으로 끝나면 안 된다.
