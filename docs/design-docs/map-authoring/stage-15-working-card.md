# Stage 15 작업 카드

## 상태

- 코드 적용 초안, 플레이 검증 대기

## 스테이지 목표

- 성 위치 `[3,3]`으로 2사분면 미니 보스형을 만든다.
- 북서쪽 짧은 압박과 남동쪽 긴 물량을 동시에 처리하게 한다.
- 다음 구간인 3사분면으로 넘어가기 전, 왼쪽 위 성 위치 문법을 종합 시험한다.

## 전장 개요

- 성 위치: `[3,3]`
- 적 스폰 방향: 북쪽, 동쪽, 남쪽, 서쪽 모두 사용
- 플레이 감정 한 줄: "북서쪽은 숨이 짧고, 남동쪽은 끝없이 밀려온다."

## Cycle 구성

- Cycle 수: 4
- Cycle 1: 북서쪽 빠른 압박 예열
- Cycle 2: 동쪽 중장과 남쪽 지원형 압박
- Cycle 3: 서쪽 빠른 적과 남쪽 중장
- Cycle 4: 2사분면 미니 보스형 종합

## 좌표 규칙

- 그리드 크기: `14 x 14`
- 성 중심 타일: `[3,3]`
- 북쪽 루트: `[4,0] [4,1] [3,1] [3,2]`
- 동쪽 루트: `[13,5] [12,5] [11,5] [10,5] [9,5] [8,5] [7,5] [6,5] [5,5] [5,4] [4,4] [4,3]`
- 남쪽 루트: `[6,13] [6,12] [7,12] [8,12] [8,11] [8,10] [7,10] [6,10] [5,10] [4,10] [4,9] [4,8] [3,8] [3,7] [3,6] [3,5] [3,4]`
- 서쪽 루트: `[0,4] [1,4] [1,3] [2,3]`

## 장애물 좌표

- 외곽 프롭: `[1,2] [12,2] [1,11] [12,11] [2,9] [11,9]`
- 성벽: `[2,2] [4,2] [5,2] [6,3] [7,3] [8,4] [9,4] [2,5] [5,6] [6,7] [8,7] [9,8]`

## 난이도 의도

- 이 구간에서는 가장 어렵게 느껴져야 한다.
- 서쪽과 북쪽은 즉시 대응이 필요하고, 동쪽과 남쪽은 사전에 깎아야 한다.
- 닌자 해금 전후의 빠른 위협 대응 가치를 느끼게 한다.

## 검증 체크리스트

- Stage 15 성이 `[3,3]`에 표시되는가
- 2사분면 미니 보스형처럼 성이 확실히 왼쪽 위에 있는가
- 북서쪽 압박이 너무 즉사형이 아닌가
- 동쪽과 남쪽 긴 우회 경로가 킬존으로 읽히는가
