# Stage 2 작업 카드

## 상태

- 코드 적용 완료
- 플레이 검증 대기

이 작업 카드는 현재 `campaign_data.dart`에 들어간 Stage 2 구현 초안과 좌표를 맞춘다.

## Stage 2 목표

- Stage 1의 사방 압박 구조를 유지한다
- 모든 방향이 같은 위협이 아니라는 점을 가르친다
- 플레이어가 `먼저 막아야 할 방향`을 판단하게 만든다
- 난이도는 적 체력보다 `동선 길이 차이`와 `스폰 방향별 강약`으로 만든다

## 전장 개요

- 성 위치: 중앙 고정
- 적 스폰: 북 / 동 / 남 / 서 4방향 모두 사용
- 실제 스폰 위치: 각 변 내부에서 랜덤
- 전선 화살표: 각 방향 대표 위치에 고정
- 플레이 감정 한 줄: `사방은 그대로지만, 동쪽이 더 빨리 무너지는 Stage`

## 핵심 변화

- 동쪽은 가장 짧고 빠른 압박이다
- 북쪽은 왼쪽으로 크게 꺾여 긴 우회를 만든다
- 남쪽은 오른쪽으로 크게 돌아 늦게 몰린다
- 서쪽은 중간 길이로, 동쪽만 보다가 놓치기 쉽다

## Cycle 구성

- Cycle 1: 4방향 모두 열림, 동쪽에 빠른 척후병 소수 추가
- Cycle 2: 동쪽 압박 강화, 북/서 일반 적 증가
- Cycle 3: 동쪽 빠른 압박 + 북쪽 일반 압박 + 남쪽 보조 압박을 동시에 처리

## 좌표 규칙

- 그리드 기준: `14 x 14`
- 성 중심 타일: `[6, 6]`
- 북쪽 루트:
  - `[5,0] -> [5,1] -> [5,2] -> [4,2] -> [3,2] -> [3,3] -> [3,4] -> [4,4] -> [5,4] -> [6,4] -> [6,5]`
- 동쪽 루트:
  - `[13,6] -> [12,6] -> [11,6] -> [10,6] -> [9,6] -> [8,6] -> [7,6]`
- 남쪽 루트:
  - `[8,13] -> [8,12] -> [9,12] -> [10,12] -> [10,11] -> [10,10] -> [9,10] -> [8,10] -> [7,10] -> [7,9] -> [7,8] -> [7,7] -> [6,7]`
- 서쪽 루트:
  - `[0,7] -> [1,7] -> [2,7] -> [3,7] -> [3,8] -> [4,8] -> [5,8] -> [5,7] -> [5,6]`

## 장애물 좌표

- 북쪽 우회 벽:
  - `[5,3]`, `[6,3]`, `[7,3]`
- 동쪽 관문 벽:
  - `[9,5]`, `[9,7]`, `[10,5]`, `[10,7]`
- 남쪽 우회 벽:
  - `[5,9]`, `[6,9]`, `[8,9]`, `[9,9]`
- 서쪽 차단 벽:
  - `[3,5]`, `[3,6]`

## 배치 유도

- 첫 킬존:
  - 동쪽 짧은 길 주변 `[8,5] ~ [10,7]`
- 보조 킬존:
  - 북서 우회 합류 지점 `[3,4] ~ [6,5]`
- 후퇴 거점:
  - 성 오른쪽과 아래쪽 `[7,6] ~ [8,8]`
- 위험 구역:
  - 동쪽 직선 압박선

## UI/UX 규칙

- Stage 1의 도움말/액션 바 규칙을 유지한다
- 시작 직후 도움말:
  - `동쪽 길이 가장 짧습니다. 먼저 막을 방향을 정하세요.`
- 도움말 배너는 HUD 바로 아래에서 1~2줄로 표시한다

## 검증 체크리스트

- Cycle 1부터 사방에서 적이 오는가
- 동쪽이 Stage 1보다 확실히 빠른 압박으로 느껴지는가
- 북쪽과 남쪽은 장애물 때문에 대응 시간이 생기는가
- 동쪽을 먼저 막아야 한다는 판단이 자연스럽게 드는가
- Stage 1보다 어렵지만 실패 이유가 읽히는가
