# Stage 13 작업 카드

## 상태

- 코드 적용 초안, 플레이 검증 대기

## 스테이지 목표

- 성 위치 `[4,4]`로 2사분면 중심부에 들어간다.
- 북쪽과 서쪽이 동시에 빨라지는 압박을 소개하고, 아래쪽 후퇴 거점의 중요성을 만든다.

## 전장 개요

- 성 위치: `[4,4]`
- 적 스폰 방향: 북쪽, 동쪽, 남쪽, 서쪽 모두 사용
- 플레이 감정 한 줄: "북서쪽이 좁아졌지만, 아래쪽으로 버틸 공간이 있다."

## Wave 구성

- Wave 수: 4
- Wave 1: 북쪽 빠른 진입과 서쪽 견제
- Wave 2: 동쪽 긴 우회와 남쪽 지원형 압박
- Wave 3: 북서 동시 압박 강화
- Wave 4: 남쪽 배너와 동쪽 중장 합류

## 좌표 규칙

- 그리드 크기: `14 x 14`
- 성 중심 타일: `[4,4]`
- 북쪽 루트: `[4,0] [4,1] [3,1] [2,1] [2,2] [3,2] [4,2] [4,3]`
- 동쪽 루트: `[13,6] [12,6] [11,6] [10,6] [9,6] [8,6] [7,6] [6,6] [6,5] [5,5] [5,4]`
- 남쪽 루트: `[6,13] [6,12] [7,12] [8,12] [8,11] [8,10] [7,10] [6,10] [5,10] [5,9] [5,8] [4,8] [4,7] [4,6] [4,5]`
- 서쪽 루트: `[0,5] [1,5] [2,5] [2,4] [3,4]`

## 장애물 좌표

- 외곽 프롭: `[1,2] [12,2] [1,11] [12,11] [2,9] [11,9]`
- 성벽: `[5,2] [6,2] [7,3] [8,3] [6,4] [7,4] [8,5] [9,5] [3,6] [6,7] [8,8] [10,8]`

## 난이도 의도

- 북서 압박이 동시에 오면 흔들려야 한다.
- 남쪽 후퇴 거점에 타워를 깔아두면 안정적으로 회복할 수 있어야 한다.
- 마법사 광역이 동쪽 긴 우회에서 충분히 강하게 느껴져야 한다.

## 검증 체크리스트

- Stage 13 성이 `[4,4]`에 표시되는가
- 서쪽 루트가 짧지만 즉시 사망형은 아닌가
- 남쪽 후퇴 거점에 배치 가능한 공간이 남아 있는가
- 장애물이 경로 위에 놓이지 않는가
