# Stage 3 작업 카드

## 상태

- 코드 적용 완료
- 플레이 검증 대기

## Stage 3 목표

- 첫 중장 체크를 본격적으로 시작한다
- 플레이어가 단순 궁수 화력만으로는 부족하다는 점을 느끼게 한다
- 병영, 마법사, 저지 역할의 필요성을 배운다

## 전장 개요

- 성 위치: 중앙 고정
- 적 스폰: 북 / 동 / 남 / 서 4방향 모두 사용
- 핵심 위험 방향: 동쪽
- 플레이 감정 한 줄: `동쪽 중장을 묶어두지 못하면 성 앞에서 무너지는 Stage`

## Wave 구성

- Wave 1: 동쪽에 방패 보병 1기 등장
- Wave 2: 동쪽 방패 보병 증가, 북/서/남 압박 유지
- Wave 3: 동쪽 중장 압박 강화
- Wave 4: 중장 압박과 사방 분산을 함께 처리하는 최종 체크

## 좌표 규칙

- 북쪽 루트:
  - `[7,0] -> [7,1] -> [7,2] -> [7,3] -> [6,3] -> [5,3] -> [5,4] -> [5,5] -> [6,5]`
- 동쪽 루트:
  - `[13,7] -> [12,7] -> [11,7] -> [10,7] -> [9,7] -> [8,7] -> [7,7] -> [7,6]`
- 남쪽 루트:
  - `[5,13] -> [5,12] -> [5,11] -> [4,11] -> [3,11] -> [3,10] -> [3,9] -> [4,9] -> [5,9] -> [6,9] -> [6,8] -> [6,7]`
- 서쪽 루트:
  - `[0,5] -> [1,5] -> [2,5] -> [3,5] -> [4,5] -> [5,5] -> [5,6]`

## 장애물 의도

- 동쪽 길 위아래에 벽을 둬 중장 압박을 좁은 관문처럼 읽게 한다
- 남쪽은 길게 우회시켜 늦게 몰리는 보조 압박으로 만든다
- 서쪽은 빠른 척후 압박으로 주의 분산을 만든다

## 장애물 좌표

- 북쪽 분리 벽:
  - `[6,2]`, `[8,2]`
- 동쪽 관문 벽:
  - `[9,6]`, `[9,8]`, `[10,6]`, `[10,8]`
- 남쪽 우회 벽:
  - `[5,10]`, `[6,10]`, `[7,10]`
- 서쪽 차단 벽:
  - `[3,6]`, `[4,6]`

## 검증 체크리스트

- 방패 보병이 확실히 새 위협으로 느껴지는가
- 동쪽 중장을 묶어둘 타워 선택이 필요하게 느껴지는가
- 사방 압박이 유지되지만 동쪽 대응이 가장 중요하게 읽히는가
