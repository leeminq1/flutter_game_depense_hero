# Stage 12 작업 카드

## 상태

- 코드 적용 초안, 플레이 검증 대기

## 스테이지 목표

- 성 위치 `[5,4]`로 2사분면 감각을 유지하되, Stage 11보다 북쪽 압박을 더 빠르게 느끼게 한다.
- 남동쪽 긴 우회 경로를 통해 오른쪽 넓은 킬존의 가치를 다시 확인시킨다.

## 전장 개요

- 성 위치: `[5,4]`
- 적 스폰 방향: 북쪽, 동쪽, 남쪽, 서쪽 모두 사용
- 플레이 감정 한 줄: "북쪽은 빨라졌고, 남동쪽은 길게 돈다."

## Wave 구성

- Wave 수: 4
- Wave 1: 북쪽 빠른 진입과 서쪽 견제
- Wave 2: 동쪽 긴 우회와 북쪽 원거리 압박
- Wave 3: 북쪽, 서쪽, 동쪽을 동시에 강화
- Wave 4: 동쪽 물량과 북서 긴급 방어를 함께 요구

## 좌표 규칙

- 그리드 크기: `14 x 14`
- 성 중심 타일: `[5,4]`
- 북쪽 루트: `[5,0] [5,1] [6,1] [7,1] [7,2] [6,2] [5,2] [5,3]`
- 동쪽 루트: `[13,6] [12,6] [11,6] [10,6] [9,6] [8,6] [7,6] [7,5] [6,5] [6,4]`
- 남쪽 루트: `[7,13] [7,12] [8,12] [9,12] [9,11] [9,10] [8,10] [7,10] [6,10] [6,9] [6,8] [5,8] [5,7] [5,6] [5,5]`
- 서쪽 루트: `[0,5] [1,5] [2,5] [3,5] [3,4] [4,4]`

## 장애물 좌표

- 외곽 프롭: `[1,2] [12,2] [1,11] [12,11] [2,9] [11,9]`
- 성벽: `[4,2] [8,2] [9,3] [10,3] [7,4] [8,4] [10,4] [4,6] [7,7] [8,8] [3,6] [9,8]`

## 난이도 의도

- 북쪽 성문 압박에서 첫 흔들림을 만든다.
- 오른쪽 긴 킬존을 먼저 만들면 동쪽 물량을 안정적으로 처리할 수 있어야 한다.
- Stage 11보다 빠르지만 Stage 13보다 복잡하지 않아야 한다.

## 검증 체크리스트

- Stage 12 성이 `[5,4]`에 표시되는가
- 북쪽 루트가 성 바로 위 `[5,3]`에서 끝나는가
- 장애물이 몬스터 경로 위에 놓이지 않는가
- 오른쪽 넓은 킬존이 실제 화면에서 비어 보이는가
