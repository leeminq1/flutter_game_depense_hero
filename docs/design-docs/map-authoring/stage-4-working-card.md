# Stage 4 작업 카드

## 상태

- 코드 적용 완료
- 플레이 검증 대기

## Stage 4 목표

- 성 근처 최종 방어선의 중요성을 가르친다
- Stage 1~3보다 우회 길을 줄여 성 앞 압박을 강하게 만든다
- 플레이어가 외곽 킬존뿐 아니라 성 앞 후퇴 거점도 준비하게 한다

## 전장 개요

- 성 위치: 중앙 고정
- 적 스폰: 북 / 동 / 남 / 서 4방향 모두 사용
- 핵심 위험: 성 바로 앞 4방향 진입선
- 플레이 감정 한 줄: `외곽에서 놓친 적을 성 앞에서 마지막으로 막는 Stage`

## Cycle 구성

- Cycle 1: 사방 약압박
- Cycle 2: 사방 일반 압박 증가
- Cycle 3: 동쪽 중장 + 남쪽 압박 추가
- Cycle 4: 성 근처 직선 압박 종합

## 좌표 규칙

- 북쪽 루트:
  - `[6,0] -> [6,1] -> [6,2] -> [6,3] -> [6,4] -> [6,5]`
- 동쪽 루트:
  - `[13,6] -> [12,6] -> [11,6] -> [10,6] -> [9,6] -> [8,6] -> [7,6]`
- 남쪽 루트:
  - `[6,13] -> [6,12] -> [6,11] -> [6,10] -> [6,9] -> [6,8] -> [6,7]`
- 서쪽 루트:
  - `[0,6] -> [1,6] -> [2,6] -> [3,6] -> [4,6] -> [5,6]`

## 장애물 의도

- 성 대각선 주변에 벽을 둬 배치 공간을 압축한다
- 경로 자체는 짧게 유지해 성 근처 압박을 만든다
- 플레이어가 최종 방어 라인을 의식하게 만든다

## 장애물 좌표

- 성 근처 압축 벽:
  - `[5,5]`, `[7,5]`, `[5,7]`, `[7,7]`
- 외곽 대각 보조 벽:
  - `[4,4]`, `[8,4]`, `[4,8]`, `[8,8]`

## 검증 체크리스트

- 성 앞이 Stage 1~3보다 더 위험하게 느껴지는가
- 후퇴 거점 배치가 필요하게 느껴지는가
- 직선 압박이 과하게 억울하지는 않은가
