# Stage 6 작업 카드

## 상태

- 코드 적용 초안
- 플레이 검증 대기
- 성 위치 변경을 처음 사용하는 Stage

## Stage 6 목표

- Stage 1~5의 중앙 성 수비 습관을 부드럽게 흔든다
- 성이 오른쪽 위로 이동했을 때 짧은 북동 압박과 넓은 하단 킬존이 어떻게 달라지는지 보여준다
- 앞으로 Stage 6~10이 1사분면 성 구간이라는 점을 플레이어에게 학습시킨다

## 전장 개요

- 성 위치: `[7,5]`
- 성 위치 패턴: 1사분면, 오른쪽 위 살짝 이동
- 적 스폰: 북 / 동 / 남 / 서 4방향 모두 사용
- 핵심 위험 방향: 동쪽과 북쪽
- 보상 공간: 성 아래쪽과 왼쪽 아래 넓은 배치 공간
- 플레이 감정 한 줄: `성이 오른쪽 위로 움직였지만, 진짜 싸움은 아래 넓은 공간에서 벌어진다`

## Cycle 구성

- Cycle 1: 4방향 모두 열되, 동쪽 빠른 압박을 먼저 체감시킨다
- Cycle 2: 동쪽 늑대 척후와 북쪽 방패 보병으로 짧은 압박을 강화한다
- Cycle 3: 동쪽 중장, 남쪽 물량, 서쪽 척후를 동시에 처리하게 한다
- Cycle 4: 동쪽 중장과 북쪽 빠른 적, 서쪽 지휘관을 함께 처리하는 최종 체크

## 좌표 규칙

- 그리드 기준: `14 x 14`
- 성 중심 타일: `[7,5]`
- 북쪽 루트:
  - `[7,0] -> [7,1] -> [8,1] -> [9,1] -> [9,2] -> [8,2] -> [7,2] -> [7,3] -> [7,4]`
- 동쪽 루트:
  - `[13,5] -> [12,5] -> [11,5] -> [10,5] -> [9,5] -> [8,5]`
- 남쪽 루트:
  - `[6,13] -> [6,12] -> [5,12] -> [4,12] -> [4,11] -> [4,10] -> [5,10] -> [6,10] -> [7,10] -> [8,10] -> [8,9] -> [8,8] -> [7,8] -> [7,7] -> [7,6]`
- 서쪽 루트:
  - `[0,7] -> [1,7] -> [2,7] -> [3,7] -> [3,6] -> [4,6] -> [5,6] -> [5,5] -> [6,5]`

## 장애물 의도

- 성 가까운 오른쪽 위에는 성벽 계열을 사용해 짧은 압박을 시각적으로 강조한다
- 성 아래쪽에는 넓은 배치 공간을 남겨 플레이어가 킬존을 만들 수 있게 한다
- 서쪽과 남쪽은 길게 돌아오게 만들어 하단 공간에서 골드와 시간을 벌 수 있게 한다
- 동쪽은 완전히 막지 않고 짧은 관문만 만들어 긴급 방어의 압박을 남긴다

## 장애물 좌표

- 북동 성벽:
  - `[8,3]`, `[9,3]`, `[9,4]`, `[10,4]`
- 동쪽 관문:
  - `[10,6]`, `[10,7]`, `[11,6]`
- 하단 킬존 보조 벽:
  - `[5,8]`, `[6,8]`, `[9,8]`
- 서쪽 접근 차단:
  - `[4,5]`, `[4,7]`

## ASCII 구현 초안

범례:

- `C` = 성
- `N` = 북쪽 경로
- `E` = 동쪽 경로
- `S` = 남쪽 경로
- `W` = 서쪽 경로
- `X` = 장애물
- `K` = 추천 킬존

## 검증 체크리스트

- 성이 오른쪽 위로 이동했다는 점이 눈에 바로 들어오는가
- 동쪽이 짧고 위험한 방향으로 느껴지는가
- 남쪽과 서쪽은 충분히 돌아와서 하단 킬존을 만들 시간이 있는가
- Stage 5보다 새롭지만, 갑자기 불공평하게 어렵지는 않은가
- 장애물이 성 위치와 어울리는 에셋 언어로 보이는가
