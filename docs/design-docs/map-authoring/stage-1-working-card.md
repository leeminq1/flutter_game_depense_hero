# Stage 1 작업 카드

## 상태

- 기준 확정
- Stage 2 이후 설계의 베이스가 되는 잠금 카드

## Stage 1 목표

- 첫 스테이지부터 사방 압박이 들어와 긴장감이 있어야 한다
- 하지만 장애물 때문에 적이 한 번씩 돌아오도록 만들어 억울한 난이도는 피한다
- 플레이어가 `맵을 읽고 배치하는 재미`를 바로 느끼게 한다

## 전장 개요

- 성 위치: 중앙 고정
- 적 스폰: 북 / 동 / 남 / 서 4방향 모두 사용
- 실제 스폰 위치: 각 변 내부에서 랜덤
- 전선 화살표: 각 방향 대표 위치에 고정
- 플레이 감정 한 줄: `바쁘지만 읽히는 사방 압박 입문`

## Cycle 구성

- Cycle 수: 3
- Cycle 1: 4방향 모두 활성화, 북/서가 메인 압박, 동/남은 보조 압박
- Cycle 2: 4방향 유지, 적 수 증가
- Cycle 3: 4방향 유지, 약한 중장 체크 추가

## 장애물 설계 의도

- 북쪽 적은 중앙 직선으로 바로 내려오지 못하고 한 번 꺾여야 한다
- 서쪽 적은 성 왼쪽 벽 때문에 북서 킬존 쪽으로 한 번 모여야 한다
- 동쪽 적은 오른쪽 차단 벽 때문에 아래쪽 보조 킬존으로 흐른다
- 남쪽 적은 하단 차단 벽 때문에 우회 진입한다
- 중앙 성 가까이는 성벽 계열로 읽히고, 외곽은 생활/보급/잔해 프롭으로 읽혀야 한다

## 장애물 에셋 규칙

- 성 근처: `bastion_wall_chunk` 같은 성벽 계열 사용
- 외곽 생활 프롭: `road_signpost`, `well`, `wooden_fence_segment`, `wagon_wreck`
- 외곽 보급 프롭: `supply_crate`, `siege_crate`
- 규칙 요약: 안쪽은 방어 구조물, 바깥은 생활/잔해/보급 구조물

## 좌표 규칙

- 그리드 기준: `14 x 14`
- 성 중심 타일: `[6, 6]`
- 북쪽 루트:
  - `[6,0] -> [6,1] -> [6,2] -> [5,2] -> [4,2] -> [4,3] -> [4,4] -> [5,4] -> [6,4] -> [6,5]`
- 서쪽 루트:
  - `[0,6] -> [1,6] -> [2,6] -> [2,5] -> [2,4] -> [3,4] -> [4,4] -> [5,4] -> [5,5] -> [5,6]`
- 동쪽 루트:
  - `[13,6] -> [12,6] -> [11,6] -> [10,6] -> [10,7] -> [10,8] -> [9,8] -> [8,8] -> [7,8] -> [7,7] -> [7,6]`
- 남쪽 루트:
  - `[7,13] -> [7,12] -> [7,11] -> [8,11] -> [9,11] -> [9,10] -> [9,9] -> [9,8] -> [8,8] -> [7,8] -> [6,8] -> [6,7]`

## 장애물 좌표

- 북쪽 차단 벽:
  - `[5,3]`, `[6,3]`, `[7,3]`, `[8,3]`
- 서쪽 차단 벽:
  - `[3,5]`, `[3,6]`, `[3,7]`
- 동쪽 차단 벽:
  - `[9,5]`, `[9,6]`, `[9,7]`
- 남쪽 차단 벽:
  - `[5,9]`, `[6,9]`, `[7,9]`, `[8,9]`

## 배치 유도

- 북서 첫 킬존:
  - `[4,4] ~ [6,5]`
- 남동 보조 킬존:
  - `[7,8] ~ [9,8]`
- 경제 욕심 구역:
  - 좌하단 또는 우하단 외곽
- 위험 구역:
  - 성 바로 앞 4방향 진입선

## 전선 화살표 규칙

- 북쪽: 파란색
- 동쪽: 초록색
- 남쪽: 빨간색
- 서쪽: 노란색
- 화살표는 매 스폰마다 이동하지 않는다
- 실제 적은 각 변 내부에서 랜덤 위치로 등장하지만, 화살표는 방향 대표 위치에 고정한다
- 북쪽 화살표는 HUD와 겹치지 않도록 전장 안쪽 여백에 둔다

## Stage 1 UI/UX 규칙

- 스테이지 시작 직후 상단 도움말 배너에 `아래 카드를 클릭해서 건물을 배치하세요.`를 3초 동안 표시한다
- 건물을 배치한 직후 상단 도움말 배너에 `건물을 선택해 업그레이드나 철거가 가능합니다.`를 3초 동안 표시한다
- 상단 도움말 배너는 골드 / Cycle / Stage HUD 바로 아래에 붙은 느낌으로 배치한다
- 상단 도움말 배너는 문장 길이에 따라 1줄 또는 2줄로 유동적으로 표시한다
- 건물을 선택했을 때 보이는 업그레이드/철거 액션 바는 3초 뒤 자동으로 사라진다
- 액션 바가 사라질 때는 건물 선택 상태도 함께 해제한다
- 플레이어가 빈 맵을 터치하면 선택 상태를 정리하고 기본 도움말 흐름으로 돌아간다

## Stage 1 애니메이션 규칙

- 적의 이동 방향과 보행 모션 방향은 반드시 일치해야 한다
- 오른쪽에서 왼쪽으로 이동하면 왼쪽 걷기 모션이어야 한다
- 왼쪽에서 오른쪽으로 이동하면 오른쪽 걷기 모션이어야 한다
- 방향 불일치는 Stage 1 첫 인상을 해치므로 우선 수정 대상으로 본다

## 난이도 의도

- `쉬운 튜토리얼`이 아니라 `바쁘지만 읽히는 입문 난이도`를 목표로 한다
- 난이도는 적 체력만으로 올리지 않고, 사방 판단과 우회 동선 읽기로 만든다
- Stage 1에서 플레이어는 사방 압박을 처음 경험하지만, 장애물 덕분에 대응 시간을 확보해야 한다

## 검증 체크리스트

- Cycle 1부터 실제로 사방에서 적이 오는가
- 적이 장애물 때문에 직선이 아니라 우회하는가
- 북쪽 화살표가 HUD와 겹치지 않는가
- 왼쪽/오른쪽 이동 적이 각각 올바른 보행 모션을 쓰는가
- 건물 선택 액션 바가 3초 뒤 자동으로 사라지는가
- 도움말 배너가 상황에 맞게 1~2줄로 자연스럽게 보이는가
