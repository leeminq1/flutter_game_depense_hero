# Stage 14 작업 카드

## 상태

- 코드 적용 초안, 플레이 검증 대기

## 스테이지 목표

- 성 위치 `[3,4]`로 왼쪽 압박을 분명하게 만든다.
- 서쪽은 긴급 방어, 동쪽은 장거리 물량이라는 역할 차이를 강하게 보여준다.

## 전장 개요

- 성 위치: `[3,4]`
- 적 스폰 방향: 북쪽, 동쪽, 남쪽, 서쪽 모두 사용
- 플레이 감정 한 줄: "서쪽은 바로 막아야 하고, 동쪽은 미리 깎아야 한다."

## Wave 구성

- Wave 수: 4
- Wave 1: 서쪽 긴급 압박 소개
- Wave 2: 북쪽 원거리와 동쪽 중장
- Wave 3: 서쪽 빠른 적과 남쪽 중장 합류
- Wave 4: 북서 긴급과 동쪽 장거리 물량 종합

## 좌표 규칙

- 그리드 크기: `14 x 14`
- 성 중심 타일: `[3,4]`
- 북쪽 루트: `[3,0] [3,1] [4,1] [5,1] [5,2] [4,2] [3,2] [3,3]`
- 동쪽 루트: `[13,6] [12,6] [11,6] [10,6] [9,6] [8,6] [7,6] [6,6] [5,6] [5,5] [4,5] [4,4]`
- 남쪽 루트: `[6,13] [6,12] [7,12] [8,12] [8,11] [8,10] [7,10] [6,10] [5,10] [4,10] [4,9] [4,8] [3,8] [3,7] [3,6] [3,5]`
- 서쪽 루트: `[0,5] [1,5] [1,4] [2,4]`

## 장애물 좌표

- 외곽 프롭: `[1,2] [12,2] [1,11] [12,11] [2,9] [11,9]`
- 성벽: `[4,3] [5,3] [6,3] [7,4] [8,4] [6,5] [8,5] [9,5] [2,6] [5,7] [7,8] [9,8]`

## 난이도 의도

- 서쪽 방어가 늦으면 빠르게 흔들린다.
- 동쪽은 길기 때문에 초반 배치가 좋으면 안정적으로 처리되어야 한다.
- 첫 타워 위치 선택이 Stage 13보다 더 중요하게 느껴져야 한다.

## 검증 체크리스트

- Stage 14 성이 `[3,4]`에 표시되는가
- 서쪽 압박이 짧지만 억울하지 않은가
- 동쪽 긴 우회가 충분히 보이는가
- 타워가 파괴되어도 재건설할 수 있는 성 주변 빈 칸이 있는가
