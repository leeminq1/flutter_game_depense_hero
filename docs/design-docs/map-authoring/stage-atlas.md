## Front 패턴

- Stage 1~5: 북쪽 중심에서 북+동으로 확장한다.
- Stage 6~10: 북+서, 이후 북+서+남.
- Stage 11~15: 남+서, 이후 남+서+동.
- Stage 16~20: 남+동, 이후 남+동+북.
- Stage 21~30: 네 방향 모두 사용한다.

## 이벤트 Stage

이벤트 Stage는 `4, 7, 10, 13, 16, 19, 22, 25, 28`이다. 이벤트 보스의 정확한
HP/피해는 자동 스냅샷의 Stage Event Boss Dice 표를 사용한다.
