# Combat Pillars

## Pillar 1: Readable Threat

Players should know why they are losing.

Design implications:
- Enemy roles need clear silhouettes and motion patterns.
- Status effects should have unambiguous visual language.
- The path or lane structure should support anticipation.
- Special abilities should be visible in motion, not only hidden in numbers or logs.

## Pillar 2: Meaningful Placement

Tower placement should matter more than finger speed.

Design implications:
- Map geometry must create tradeoffs, not obvious best slots everywhere.
- Range, line coverage, and synergy should be legible.
- Upgrade choices should shift strategy, not only DPS totals.

## Pillar 3: Controlled Escalation

The game should create pressure through composition, timing, and counterplay.

Design implications:
- Wave design should mix roles intentionally.
- Spawn spikes need performance budgets.
- Bosses should test understanding, not just stat walls.
