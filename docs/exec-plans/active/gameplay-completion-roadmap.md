# Gameplay Completion Roadmap

## Goal

Move the project from an internally playable prototype to a stable first public playable.

## Phase 1: Gameplay Complete

- tune stage, wave, and reward balance
- shape the meta progression curve
- improve tutorial and early-game UX
- remove obvious first-session confusion

Exit condition:

- a new player can reach Stage 5 without external explanation
- early-stage failure feels understandable rather than arbitrary

## Phase 2: Content Complete

- finish missing art and BGM
- tighten final tower and enemy visual feedback
- improve results, unlock, and progression presentation

Exit condition:

- the game looks coherent across towers, enemies, maps, and reward flow

## Phase 3: Stabilization

- improve save and load reliability
- measure device performance on real hardware
- expand test coverage for progression, rewards, and failure cases

Exit condition:

- no major progression blockers
- acceptable late-wave performance on target devices

## Phase 4: Release Preparation

- connect ad flow safely
- finalize store build settings and packaging
- run final QA pass

Exit condition:

- the build is stable enough to hand to external testers or publish as a first playable

## Current Focus

Current active work:

- first five stage balance pass
- first-playable tutorial and onboarding pass

Reason:

- the project already has enough systems to play, so the highest-value work now is reducing confusion and improving early retention
