# 그래픽 에셋

## 현재 휴대전화 스크린샷 출력

정리된 스크린샷 저장 위치:

```text
docs/generated/google-play/screenshots/
```

출력 크기:

```text
1080 x 2640
```

원본 스크린샷의 픽셀 크기와 동일하게 유지합니다.

## 업로드할 파일

```text
phone-screenshot-01-title.png
phone-screenshot-02-camp.png
phone-screenshot-03-hero.png
phone-screenshot-04-briefing.png
phone-screenshot-05-battle.png
```

## 대체 텍스트 초안

Play Console에서 이미지 설명을 요구하면 아래 문구를 사용하세요.

```text
픽셀 판타지 키 아트가 표시된 PIXEL GUARD:WAVE 타이틀 화면.
```

```text
스테이지 선택과 첫 방어 구역이 표시된 캠페인 허브 화면.
```

```text
다섯 가지 방어 역할을 고르는 영웅 선택 화면.
```

```text
적 이동 경로와 웨이브 미리보기를 보여주는 스테이지 브리핑 화면.
```

```text
공성 웨이브 중 타워, 벽, 영웅, 적이 표시된 게임플레이 화면.
```

## Google Play 참고

- 지원 기기 유형별로 최대 8장의 스크린샷을 올릴 수 있습니다.
- 스크린샷은 JPEG 또는 알파 없는 24-bit PNG여야 합니다.
- 최소 크기는 320px, 최대 크기는 3840px입니다.
- 긴 변은 짧은 변의 2배를 넘으면 안 됩니다.
- 현재 1080x2640 스크린샷은 2640이 1080의 2배보다 작으므로 휴대전화 스크린샷 규격에 맞습니다.

## 사용한 문구

```text
성채를 지켜라
캠페인을 준비하라
영웅을 선택하라
공성 정보를 확인하라
모든 전선을 버텨라
```
