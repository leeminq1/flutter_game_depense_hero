## 현재 기준

- 현재 릴리즈 매니페스트에는 `INTERNET` 권한이 없습니다.
- `pubspec.yaml` 기준 광고, 분석, Firebase, 오류 보고, 계정 로그인, 결제, 클라우드 저장 SDK가 없습니다.
- 진행도, 설정, 업그레이드, 보상 기록은 Isar로 기기 내부에 저장됩니다.
- 광고, 분석, 오류 보고, 결제, 로그인, 푸시 알림, 서버 기능을 추가하면 제출 전에 개인정보처리방침과 데이터 보안 양식을 다시 업데이트해야 합니다.
