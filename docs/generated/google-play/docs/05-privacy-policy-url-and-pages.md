## GitHub Pages 설정

GitHub 저장소에서:

1. `Settings` 열기.
2. `Pages` 열기.
3. `Build and deployment`에서 `Deploy from a branch` 선택.
4. Branch: `main`.
5. Folder: `/docs`.
6. 저장.

GitHub Pages 배포가 끝나면 아래 URL에서 개인정보처리방침이 열려야 합니다.

