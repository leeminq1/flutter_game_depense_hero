## 보안 관행

전송 중 암호화 여부를 묻는 경우:

```text
해당 없음. 현재 릴리즈는 사용자 데이터를 기기 밖으로 전송하지 않습니다.
```

사용자가 데이터 삭제를 요청할 수 있는지 묻는 경우:

```text
현재 릴리즈는 개발자 서버에 사용자 데이터를 수집하지 않으므로 서버 측 삭제 요청은 해당 없음입니다. 사용자는 앱 삭제 또는 Android 설정의 앱 저장공간 삭제로 로컬 데이터를 삭제할 수 있습니다.
```

```text
아니요
```
