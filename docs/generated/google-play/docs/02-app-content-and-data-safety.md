# 앱 콘텐츠 및 데이터 보안

Google Play Console의 `앱 콘텐츠`와 `데이터 보안` 섹션에서 현재 코드 기준으로 사용한다.

## 개인정보처리방침 URL

```text
https://leeminq1.github.io/flutter_game_depense_hero/privacy-policy/
```

## 현재 데이터 처리 요약

```text
게임 진행도, 설정, Stage 진행도, 업그레이드 상태, 보상 수령 기록은 사용자 기기에 로컬로 저장됩니다. 현재 앱에는 보상형 재시도 광고를 위한 Google Mobile Ads SDK가 포함되어 있으며 Android manifest에 AD_ID 권한이 선언되어 있습니다.
```

```text
예
```

사유:

```text
개발자 서버는 계정/진행 데이터를 수집하지 않지만, Google Mobile Ads SDK가 광고 제공을 위해 광고 ID 등 광고 관련 데이터를 처리할 수 있습니다.
```

## 로컬 저장 데이터

다음 정보는 기기 내부 저장소에만 저장된다.

- 게임 진행도
- Stage 진행도
- 메타 업그레이드
- 보상 수령 상태
- 오디오 설정

서버 계정이 없으므로 서버 측 삭제 대상은 없다. 사용자는 앱 삭제 또는 Android 앱 저장공간 삭제로
로컬 데이터를 지울 수 있다.

## 권한 및 API

현재 main manifest 기준:

```text
android.permission.AD_ID
com.google.android.gms.ads.APPLICATION_ID
```

debug/profile의 `INTERNET` 권한은 Flutter 개발용 매니페스트에 있다. 광고 SDK나 Android Gradle
merge 결과에 따라 릴리즈 manifest 최종 권한은 AAB 검토에서 다시 확인한다.
