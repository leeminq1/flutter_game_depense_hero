# 콘텐츠 등급 및 타겟층

콘텐츠 등급 설문을 작성할 때 참고하세요. 최종 등급은 공식 설문 답변으로 정해지므로, 업로드하는 실제 빌드 기준으로 답해야 합니다.

## 앱 유형

```text
게임
```

## 카테고리

```text
전략
```

## 폭력성

현재 설명:

```text
작고 양식화된 픽셀 영웅, 타워, 판타지 적 사이의 비현실적인 판타지 전투가 포함됩니다. 피, 유혈, 신체 훼손, 사실적인 상해 묘사, 노골적인 폭력 표현은 없습니다.
```

권장 설문 답변 방향:

```text
판타지 또는 양식화된 폭력: 예
피 또는 유혈: 아니요
사실적인 폭력: 아니요
실제 사람 대상 폭력: 아니요
```

## 공포

권장 답변:

```text
강한 공포 요소는 없습니다. 일부 판타지 적은 해골형 또는 몬스터형 픽셀 캐릭터로 보일 수 있습니다.
```

## 사용자 상호작용

현재 권장 답변:

```text
사용자끼리 상호작용하거나 콘텐츠를 교환함: 아니요
사용자 위치 공유: 아니요
사용자 제작 콘텐츠 허용: 아니요
```

## 온라인 기능

현재 권장 답변:

```text
온라인 멀티플레이: 아니요
계정 또는 로그인: 아니요
채팅: 아니요
리더보드: 아니요
```

## 구매 및 광고

현재 권장 답변:

```text
디지털 구매: 아니요
무작위 유료 아이템 또는 루트박스: 아니요
광고: 아니요
```

## 타겟층

현재 권장 선택:

```text
만 13세 이상
```

사유:

```text
현재 게임은 양식화된 전투가 있는 판타지 전략 게임입니다. 아동을 특별히 대상으로 제작된 앱이 아니며, 가족 정책 프로그램에 등록하지 않습니다.
```

## 스토어 등록정보 표현

스토어 문구와 스크린샷은 일반 이용자에게 적합하게 유지하세요.

- 노골적인 폭력 표현 없음.
- 욕설 없음.
- `1위`, `최고`, `인기`, 수상 표현 같은 순위/성과 주장 없음.
- 제목, 아이콘, 스크린샷, 기능 그래픽에 가격/할인/프로모션 표현 없음.
